# docs/paper: IEEE paper (owner: lead)

- **Build:** `just paper` (pdflatex + bibtex) writes `paper.pdf`, which is committed. The build fails on undefined references or citations, overfull boxes, non-Type-1 fonts, or a missing Fig. 1 on page 1.
- **Numbers:** never type a result into `sections/*.tex`.
  - Every value is a macro in `data/metrics.tex`, generated by `python/ultra/tools/paper_data.py` from `data/curated.json` and `data/raw/` (sha256 in `data/raw/MANIFEST.txt`).
  - `data/SOURCES.md` maps each macro to its source.
  - Proof: `cd python/ultra && ../../.venv/bin/python -m pytest -q tests/test_paper_data.py`.
- **Layout:**
  - `paper.tex`: the main file;
  - `sections/`: the text;
  - `figures/`: pgfplots reading `data/*.csv`;
  - `refs.bib`: verified citations;
  - `data/raw/`: copied receipts, small files only, no models or audio.
- **Honesty rules:**
  - R1 WER from DEV only; test is sealed until `bench-freeze-v1`;
  - every speed or density number sits beside the same checkpoint's same-harness WER;
  - results are labelled exploratory until the qualifying window;
  - published comparator numbers go in a separate "reported" group.
- **Coordination:** `~/jsr/agent_paper.md` (append-only). Research log: `research/H18_ieee_paper_draft/`.
