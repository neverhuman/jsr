\begin{abstract}
Continuous speech recognition needs inexpensive, repeatable inference. \ultra{} \ReleaseVer{} pairs
a streaming Conformer transducer with a native Rust runtime combining per-row INT8 quantisation,
exact integer accumulation, and a portable log-mel front end. On full LibriSpeech DEV, greedy live
INT8 changes pooled word error rate (WER) by \RelIntEightDelta{} percentage points relative to FP32
PyTorch (95\% bootstrap bounds \RelIntEightLo{} to \RelIntEightHi{}), and cold live repetitions on
the evaluated host produce identical transcripts. On a 730-utterance LibriSpeech development panel,
we time three cold runs on one pinned Zen~2 core, including model load. \RelIsaProof{} \ColdAbstractLive{}
\ColdAbstractZip{} In a separate paced replay on one core, sixteen live streams use
\RelCapSixteenBusy\% of one core with a 95th-percentile stable-word lag of
\RelCapSixteenLagPninetyFive\,ms. \ColdAbstractFinal{} \ColdAbstractMoreAcc{} Training adds
Libri-Light audio pseudo-labelled by the Zipformer comparator; all results are exploratory and use development
data.
\end{abstract}
