  \vspace{0pt}
  \colheading{Streaming Conformer \& Per-Row Centred INT8}
  {\fontsize{8.0}{10.0}\selectfont
  Dense 16-block Conformer RNN-T ($d{=}384$, 6 heads $\times$ 64 with RoPE, causal depthwise conv $k{=}15$, 2-token stateless predictor, 500 BPE) streaming 160\,ms chunks (4 frames, 128-frame left context, zero right context) with a compact live LM; an optional 640\,ms beam-16 + 5-gram LODR commit pass reuses the exact same weights at utterance ends.

  \vspace{2pt}
  Weights quantise per channel ($s_w=\max|w|/127$); activations quantise per frame row around $c=\tfrac12(x_{\max}+x_{\min})$ with $s_a=(x_{\max}-x_{\min})/254$ and round-half-even. Output recovers exactly as $y = s_a s_w\sum x_q w_q + c\,\bar w + b$ ($\bar w$ precomputed). Since $|x_q|,|w_q|\le 127$, AVX2 \texttt{vpmaddubsw} sums stay $\le 32{,}258 < 2^{15}$ (zero saturation), giving bit-exact int32 accumulation and batch invariance (verified batch sizes 1--32).
  }
\end{minipage}\hfill
\begin{minipage}[t]{0.486\textwidth}
  \vspace{0pt}
  \colheading{Reproducible by Construction, Not by Tolerance}
  {\fontsize{8.0}{10.0}\selectfont
  \begin{itemize}[leftmargin=1.12em,itemsep=1.4pt,topsep=1pt]
    \item \textbf{Four exact kernels:} x86 AVX2 (\texttt{vpmaddubsw}), AVX-512 VNNI, ARM NEON (\texttt{sdot}/\texttt{smmla}) and a portable scalar reference; forcing scalar gives \ScalarDiffs/\ScalarUtts{} differing live transcripts.
    \item \textbf{0-ULP portable front end:} 80-band 100\,Hz log-mel uses Cody--Waite reduction and polynomial $\sin$/$\cos$/$\log$ in unfused IEEE double arithmetic so platform \texttt{libm} differences cannot flip quantisation ties.
    \item \textbf{Cross-ISA parity:} \CandIsaRuns{} witness decodes on Intel AVX2, AVX-512 VNNI and Apple M3 NEON reproduce Zen~2 transcripts on all \ScalarUtts{} panel utterances; \releasever{} matches reference decoders \ScalarUtts/\ScalarUtts{} on Linux x86-64 and Apple silicon.
    \item \textbf{Integrity:} safetensors weights verified by SHA-256 at load.
  \end{itemize}
  }

  \briefsection{02}{Benchmark Method \& Paired Statistics}
  {\fontsize{7.8}{9.8}\selectfont
  \textbf{Single core, quiet host.} One process, one inference thread pinned to one physical AMD Zen~2 core alone on its 4-core L3 complex; host timers and CI paused. Throughput is the median of three cold runs (audio-s / CPU-s), alongside full process-tree peak RSS.

  \vspace{2.5pt}
  \textbf{Paired, interleaved blocks.} Isosyll and Zipformer INT8 --- the strongest open streaming comparator near this cost and our pseudo-label teacher --- ran in the same interleaved blocks on the same core. Speed (\VsSpeedXOne\x), core-energy (\VsEnergyPctOne\%) and memory (\VsRssPctOne\%) ratios are medians of within-block ratios; WER differences (\VsDeltaOne\,pp panel, bounds \VsLoOne{} to \VsHiOne) use a paired speaker-cluster bootstrap.

  \vspace{2.5pt}
  \textbf{Selection honesty.} Because the 730-utterance panel overlaps the DEV selection half, we report the unselected C half (\CandCUtts{} utt.): live Isosyll trails Zipformer there by \textbf{\CandLiveLmCDelta\,pp} (bounds \CandLiveLmCLo{} to \CandLiveLmCHi). Isosyll \releasever{} missed its registered full-DEV edit gates and ships by owner decision.
  }

  \vspace{3.5pt}
  \briefsection{03}{Deployment, Footprint \& Hardware Power Context}
  {\fontsize{7.7}{9.7}\selectfont\raggedright
  \begin{itemize}[leftmargin=1.12em,itemsep=1.6pt,topsep=1.5pt]
    \item \textbf{One binary, three targets:} \tcli{isosyll} (\textasciitilde 1.6\,MB, pure Rust) for Linux x86-64 (glibc primary + static musl fallback), Linux arm64 and Apple-silicon macOS.
    \item \textbf{Model bundle:} \ColdRcTwoLiveLmModel\,MB INT8 safetensors plus live/commit n-gram LMs (\textasciitilde 207\,MB total download); \ColdRcTwoLiveLmRss\,MB peak RSS for live streaming.
    \item \textbf{Signed supply chain:} \tcli{SHA256SUMS} signed with the project SSH key; the installer verifies both signature and checksums before installing.
  \end{itemize}
  }

  \begin{execbox}[emerald]{CPU vs.\ GPU Hardware Power Context (External Vendor Specs)}

Those are vendor datasheet figures, not measured here, and are not comparable to the CPU-core numbers above.

  \begin{govbox}{Hard Technical Limits \& Open Frontier}
    \begin{itemize}[leftmargin=1.1em,itemsep=1.7pt,topsep=1.5pt]
      \item \textbf{Exploratory, DEV only:} Isosyll \releasever{} missed its pre-registered accuracy gates and ships by owner decision. No test-set results are claimed; LibriSpeech test sets were read before the benchmark freeze.
      \item \textbf{In-domain read English:} LibriSpeech DEV is in-domain for both Isosyll and Zipformer; conversational, accented or noisy speech may rank differently.
      \item \textbf{Live accuracy gap:} \CandLiveLmCDelta\,pp behind Zipformer on the unselected half. Error analysis points to acoustic discrimination of common words on hard audio; the next lever is fresh audio and capacity.
      \item \textbf{Optional commit-pass cost:} enabling the utterance-end commit pass reaches \ColdRcTwoFinalWer\% WER (\ColdRcTwoFinalSpeed\x) at \VsEnergyPctTwo\% of Zipformer's core energy and \ColdRcTwoFinalRss\,MB RSS.
      \item \textbf{Scope of claims:} Measured energy is CPU-core RAPL only (no wall power); GPU TDP numbers are published specs, not benchmark runs; no latency figures are claimed in this brief.
    \end{itemize}
