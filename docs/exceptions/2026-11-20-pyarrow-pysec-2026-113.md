# pyarrow 17 kept below the fixed release, until 2026-12-31

**Why it can't be upgraded now.** pyarrow 23 requires numpy ≥ 2. The trainer venv reuses the system torch 2.7 (CUDA build), which is compiled against numpy 1.x and fails to import under numpy 2.

**Exposure.** pyarrow is used only by `python/ultra/ultra/libri.py`, to read LibriSpeech parquet shards fetched from a pinned HF dataset. Every file's SHA-256 is recorded in `MANIFEST.sha256`. No untrusted or network-supplied parquet/IPC data is read, and nothing runs at inference time.

**Exit (before expiry), either:**
- a numpy-2 torch in the venv, then pyarrow ≥ 23.0.1; or
- shard decoding moved to Rust (`parquet` crate), dropping pyarrow from the venv.
