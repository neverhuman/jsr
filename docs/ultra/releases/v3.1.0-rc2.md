## Paired tests

All paired comparisons use the same 730 utterance IDs and the pinned
`ultra-score` binary, with 10,000 speaker-cluster bootstrap replicates and seed
20261122. Each displayed interval endpoint is a one-sided 95% bound. A
negative difference favors RC2.

| Registered comparison | WER difference (pp) | One-sided 95% bounds (pp) | Holm-adjusted p |
| --- | ---: | ---: | ---: |
| 160 ms live with LM vs Zipformer, +0.50 pp non-inferiority margin | +0.2838 | [-0.0195, +0.5847] | 0.26937 |
| M5 final vs Zipformer, superiority | -0.2561 | [-0.5657, +0.0478] | 0.26937 |
| Joint live and final superiority vs shipped v3.0.0 | Both components below | — | 0.32777 |

The joint claim uses the larger component p-value.

- 160 ms greedy live was -0.6160 pp [-0.8599, -0.3814] with an unadjusted p of 0.00010.
- M5 final was -0.0623 pp [-0.2758, +0.1659] with an unadjusted p of 0.32777.

The original freeze paired the RC2 outputs with the historical B0 acoustic
checkpoint under a v3.0.0 label. The table above pairs the same RC2 transcripts
with the already recorded shipped v3.0.0 transcripts. The correction required
zero new decodes. Holm rejected zero of the three claims after that correction.
